# How

Explore the codebase to answer how something works. State your interpretation when the scope is ambiguous and proceed. Trace the relevant entry points, data flow, decisions and boundaries. Write an architectural explanation a senior engineer unfamiliar with the area can use to start working confidently. Cite the relevant files.

Use a read-only subagent when available and authorized; otherwise investigate directly. For a design critique, independently examine coupling, ownership, boundaries and failure modes after establishing how the system works.
